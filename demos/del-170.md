## Sprint DEL-170

---

### [TP] [DELIANY-3458](https://deliany.youtrack.cloud/issue/DELIANY-3458) [Improvement][Invoice] Move bills from legacy to invoice templates v2, print on every platform, faster

- [x] Every bill (payment, dine-in, food check, delivery) prints with an invoice template v2, from POS and from the Back Office print history
- [x] Back Office: bill setup, template editor, receipt and print history; apply settings to selected or all active locations
- [x] Printing works on desktop browsers, iPad (Chrome & Safari), Android tablets and the POS terminal; the preview shows the bill only
- [x] Print dialog opens much faster than legacy (~0.8–2.7s → under 0.25s on emulated POS devices)
- [x] Customer name, phone, email and address can be masked on printed bills
- [x] On iPad the print sheet keeps the bill and the paper size is preselected
- [ ] Re-test on real devices (iPad, Android tablet, Sunmi / iMin, Windows POS)

### [TP] [DELIANY-3432](https://deliany.youtrack.cloud/issue/DELIANY-3432) Centralize user management

- [x] One **Users** page for Back Office and POS users, with a user detail drawer
- [x] Email-first create user: an existing email opens that user to grant access instead of creating a duplicate
- [x] Backend: users list, create user with any access, reset password, account emails sent from no-reply@deliany.co
- [x] Phone numbers no longer need to be unique; edits are limited to the current merchant; the owner keeps the OWNER role
- [x] Users management rules are also enforced on the server
