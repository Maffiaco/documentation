### 🚀 [TP] [DELIANY-3338](https://deliany.youtrack.cloud/agiles/131-3/current?issue=DELIANY-3338) [POS] Hide add Tips in Rating & Add tip screen in Confirm flow

**Issue:** The POS order confirmation flow always showed both Rating and Add Tip, with no way to hide tips when a merchant only needs rating (or tip only).

**Solution:**

- Configure the confirm-step UI via POS experiments: rating + tip, rating only, or tip only
- Hide Add Tip when rating-only is enabled; hide rating when tip-only is enabled
- Adjust layout and submit payload per mode (rating-only does not send tip; tip-only does not send rating)
- Skip the Rating & Tip step when tips experiments are off

### 🚀 [TP] [DELIANY-3352](https://deliany.youtrack.cloud/agiles/131-3/current?issue=DELIANY-3352) [Bug][POS] Cannot edit table layout

**Issue:** Opening or editing the POS table layout crashed (`Cannot read properties of undefined (reading 'position')` in JointJS stencil GridLayout), so staff could not edit floor plans.

**Solution:**

- Keep auto-generated cell ids when loading the default stencil shape and always provide a default `position`
- Sanitize layout graph JSON before load: prune orphan `embeds`/`parent` refs and ensure cells have valid geometry
- Harden the layout editor lifecycle so load, area switch, and theme toggle do not crash

### 🚀 [TP] [Bug][Storefront] Fix PDP additions selection and cart summary UI

**Issue:** Product detail additions did not follow admin config (checkbox-only instead of radio / quantity steppers), addition prices were missing, and the PDP cart showed order totals plus the amount on the Place Order button.

**Solution:**

- Match addition controls to config: radio for required pick-1, +/- steppers for multi-qty, checkbox for optional/multi
- Always show addition prices and scale addition quantities with the line quantity
- Hide Order Total / Promotion on the PDP cart and keep Place Order as a centered text-only CTA
- Show the service location phone on the OTP failed step instead of the customer/OTP number
